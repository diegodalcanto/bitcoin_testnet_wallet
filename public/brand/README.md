# Loghi

| File | Uso |
| --- | --- |
| `meetup-pisa.png` | Logo originale del Bitcoin Meetup Pisa (non usato direttamente: pesa 310 KB) |
| `meetup-pisa.webp` | Stesso logo in WebP (17 KB), mostrato nell'app |
| `internet-festival.png` | Logo originale dell'Internet Festival, per il tema chiaro |
| `internet-festival-dark.png` | Variante con la scritta chiara per il tema scuro, ricavata dall'originale: **da sostituire con la versione ufficiale, se gli organizzatori ce l'hanno** |

I file effettivamente mostrati sono elencati in `src/brand.ts`: se cambiate un logo, mettete il nuovo file
qui e aggiornate il nome in quel file. Formati consigliati: SVG, WebP o PNG leggeri (sotto i 100 KB),
perché l'app li salva sul telefono per funzionare offline.

Dove compaiono: schermata di benvenuto, piè di pagina della Home, pagina Info.
